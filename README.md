Social Media Platform

A full-stack Social Media Platform built using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). The application allows users to register, log in, create posts, like, comment, and communicate in real time.

Features
User Authentication
Create and Manage Posts
Like and Comment System
Real-Time Chat
Responsive UI
MongoDB Database Integration
Technologies Used
React.js
Node.js
Express.js
MongoDB
Socket.IO
JWT Authentication
